🛡️ ការបែងចែកសិទ្ធិសុវត្ថិភាព (Access Control)

ប្រព័ន្ធ SYSTEM MDM បានបែងចែកសិទ្ធិច្បាស់លាស់រវាង **Admin (គ្រប់គ្រងប្រព័ន្ធផ្ទាល់)** និង **Partner (ដៃគូខាងក្រៅដែលមកភ្ជាប់)** ដើម្បីធានាសុវត្ថិភាពទិន្នន័យ 100% ៖

👑 Admin Control (ផ្ទៃក្នុង)

Admin Control (គ្រប់គ្រងពេញលេញ)

សម្រាប់តែបុគ្គលិក និង Admin នៃ SYSTEM MDM តាមរយៈ Web Admin App ប៉ុណ្ណោះ។

  • អានទិន្នន័យ (GET All Data)
  • បង្កើតកុងត្រាថ្មី (POST Contracts)
  • កែប្រែទិន្នន័យ និងកាលវិភាគ (PUT / Edit)
  • លុបទិន្នន័យ (DELETE Contracts / Payments)
  • បញ្ជា Lock / Unlock ទូរស័ព្ទពីចម្ងាយ
🤝 External Partner (ខាងក្រៅ)

Partner Access (អានទិន្នន័យតែប៉ុណ្ណោះ)

សម្រាប់ប្រព័ន្ធខាងក្រៅ (App, Website, Bot, Dashboard) របស់ដៃគូដែលយក API ទៅប្រើ។

  • ទាញយកបញ្ជីដល់ថ្ងៃបង់ (Due Today / Overdue)
  • ទាញយកព័ត៌មានកុងត្រា & តារាងបង់រំលស់
  • ទាញយកប្រវត្តិបង់ប្រាក់តាម Contract ID
  • ហាមឃាត់ដាច់ខាត: មិនអាចបង្កើតថ្មី (POST)
  • ហាមឃាត់ដាច់ខាត: មិនអាចកែប្រែទិន្នន័យ (PUT/PATCH)
  • ហាមឃាត់ដាច់ខាត: មិនអាចលុបទិន្នន័យ (DELETE)
